AI ADS Website
==============

Static website package.

Deploy: upload index.html and manus-routes.json to the root of any static web host.
The original supplied HTML is included at source/ai-ads-website.html, and the project
wordmark asset is included at assets/aiads-platform-logo.svg.

The page loads React, ReactDOM, Babel, Tailwind CSS, and Google Fonts from their
version-pinned/public CDNs, so those external resources require an internet connection.
